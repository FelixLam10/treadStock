# 已知问题

更新时间：2026-10-09

## KI-DATA-001：东方财富板块及成分股数据源不可用

| 项目 | 说明 |
|---|---|
| 状态 | 上游未解决；行业热点已通过备用方案规避，概念板块仍待接入 |
| 分类 | 外部数据源不可用，不是本地筛选或页面代码缺陷 |
| 原影响范围 | 热点页行业板块、概念板块、板块成分股，以及依赖这些数据生成的龙头股/热点股观察名单 |
| 现象 | 真实东方财富板块及成分股接口在当前验证网络持续返回 HTTP 502 |
| 当前影响 | 行业热点已改用 BaoStock 行业关系快照 + 新浪全量 A 股行情本地聚合，不再依赖该接口；概念板块仍无法提供真实榜单 |
| 已有保护 | 行业行情覆盖不足时停止生成榜单；固定响应解析、空数据、七天缓存和失败降级已有自动化测试 |
| 真实验证 | 2026-10-09 在当前网络拉取 5,223 只沪深 A 股行情，成功聚合 83 个行业板块；热点专用接口返回 6 根日 K |
| 未解决原因 | 东方财富上游接口当前不可用；BaoStock 不提供概念板块关系，不能用行业分类冒充概念板块 |
| 关闭条件 | 概念板块接入并验证稳定、合规的数据源，或东方财富接口恢复并通过目标设备可用性、限频、分页和字段稳定性验收 |

处理原则：可以将“行业热点真实数据链路已验证”作为完成项，但不得把它扩大描述为“东方财富接口已恢复”或“概念板块已可用”。模拟数据测试不能替代概念板块真实接口验收。
