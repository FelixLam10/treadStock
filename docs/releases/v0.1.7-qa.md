node --test deploy/market-proxy/test/*.test.js

Web 编译成功仅证明构建兼容性；正式运行需按 [PWA 部署手册](../pwa-deployment.md) 配置代理与 HTTPS 托管。

## 提交边界

- 临时 E2E 的修改和运行日志保留在本地，不纳入本次提交。CI 明确执行单元、Provider 与 Widget 回归，不运行临时 E2E。
- 不提交 `node_modules`、Worker 本地状态、密钥或构建输出。`web/sqlite3.wasm` 与 `web/drift_worker.dart.js` 是 Web 数据库运行时必需的静态资源。
- 聚焦测试数字有重叠，不相加；历史测试报告中的覆盖率与网络记录保留其原始日期，不当作本次新测结果。
- 非生成代码覆盖率以本次 `coverage/lcov.info` 为准；详见 [更新说明](v0.1.7.md) 和 [已知问题](../known-issues.md)。
