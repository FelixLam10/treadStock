# v0.1.7 — 策略版本、行业热点与 PWA

版本：`0.1.7+9` · 日期：2026-10-19

## 新增

- **策略知识与版本管理**：支持结构化策略包导入、来源追溯、候选版本差异查看、冲突确认及手动启用；资料默认不保留脱敏正文。
- **统一策略规则**：推荐、详情与回测复用多交易日确认和趋势环境规则；新增梯级平台、均线趋势与简化缠论观察模板。
- **版本化回测**：支持从个股发起回测，保存策略版本、参数、费用、滑点和行情指纹；仅在输入一致时比较版本，交易不足 20 笔提示样本不足。
- **行业热点与筛选方案**：新增热点入口、行业榜单、龙头/热点观察名单，以及本地自定义筛选、排序与方案版本历史。
- **多市场与个股资料**：推荐支持 A 股、港股、美股切换，完善市场与币种识别；个股详情增加公司及财务摘要。
- **Web/PWA 支持**：增加浏览器本地数据库、平台能力适配、可选无状态行情代理和本地启动脚本；未部署正式站点。

## 优化与修复

- 推荐行情按市场保留最近有效快照，断网或上游异常时显示缓存来源与原始更新时间，最长保留 7 天。
- 行业热点通过打包行业关系快照与行情聚合提供备用链路，明确区分缓存、无匹配、历史不足和真实错误。
- 完善关注/取消关注的状态反馈、详情操作栏吸顶、深层页面底部导航和推荐指标说明。
- 数据库升级至 schema v6，覆盖旧版本迁移；macOS 最低系统要求调整为 12.0。
- CI SDK 对齐 Flutter 3.41.5 / Dart 3.11.3，并加入行情代理测试；Windows 包版本同步为 0.1.7.0。

## 已知限制与提测范围

- 概念板块仍待稳定数据源；行业备用链路可用不代表东方财富板块接口已恢复。本次未重新执行真实行情网络验收。
- 热点自定义方案当前仅作用于所选行业成分股；全市场/关注列表范围、策略匹配分及部分额外字段筛选仍待实现。
- 回测目前为单股票、前复权、最多 500 根日 K；历史结果和样本门槛不代表未来收益。
- PWA 正式域名、行情代理配置、Safari 安装/持久化和原生端真机体验仍需人工验收；Web 不提供等价的原生后台通知能力。设备之间不做云同步。
- 本次发布提供源码与更新说明；未上传 Android、iOS 或 macOS 安装包。
